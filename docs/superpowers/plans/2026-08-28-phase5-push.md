# Phase 5a — Push Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Send web-push reminders straight from the Worker — a nightly nudge for users with an incomplete day, and a milestone ping to the rest of the family when someone passes Day 25 / 50 / 75.

**Architecture:** A new `src/push/` module holds VAPID JWT signing, RFC 8291 payload encryption, and the send call — it depends only on `src/db/` and one web-push library. A new `src/db/push.ts` owns the existing `push_subs` table. Three authed routes under `/api/push` let the client subscribe / unsubscribe / fetch the VAPID public key. The nightly nudge is a new `src/services/nudge.ts` fired from `worker.ts`'s existing `30 15 * * *` cron branch. The milestone ping is a callback threaded into the existing `catchUpGrading` lock pass, so it fires from both the noon cron and the request-path backstop. Dead subscriptions (HTTP 404/410) are pruned in the same pass that hit them.

**Tech Stack:** Cloudflare Workers (`workerd`, `nodejs_compat`), Hono, Zod, D1, WebCrypto, one web-push library (chosen in Task 1), Vitest + `@cloudflare/vitest-pool-workers`, React 19.

**Spec:** `docs/superpowers/specs/2026-08-28-phase5-push-design.md`

## Global Constraints

- **No D1 migration.** `push_subs` already exists in `migrations/0001_init.sql` with columns `id, user_id, endpoint (UNIQUE), p256dh, auth, created_at`. Do not add a migration file.
- **No `wrangler.jsonc` change.** The `30 15 * * *` cron and all bindings are already present.
- **Payload crypto is not hand-rolled unless Task 1 proves it must be.** Use a `webcrypto`-based web-push library. The Node-only `web-push` npm package does **not** run on `workerd` — do not use it.
- **VAPID keys are Worker secrets:** `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`. All three are **optional** on `Env` — their absence is a defined, tested state (503 from routes, no-op cron), so local dev and tests run without them.
- **Nudge recipients:** users with a `status='active'` run **and** ≥1 subscription, whose current day has ≥1 incomplete goal. A complete day gets nothing.
- **Milestone recipients:** **every** other user with a subscription, regardless of their own run state (active / failed / done / never started). Never the achiever.
- **Milestone days:** exactly 25, 50, 75. Fired only on the grading pass that wins the `lockDay` claim, only when that day's grade is `passed`.
- **Push errors never block or fail grading.** The milestone callback is wrapped in `try/catch` that logs and swallows. Grading already fails open.
- **Ownership boundary:** `DELETE FROM push_subs ... WHERE endpoint = ? AND user_id = ?` for user-initiated unsubscribe. The prune path (after a push-service 404/410) deletes by endpoint alone — the push service is the authority there.
- **Icons / manifest / `vite-plugin-pwa` / offline shell are Phase 5b.** Not in this plan. The only PWA-adjacent file here is a bare `web/public/sw.js`.
- **Lucide icons only**, no emoji in JSX. (Emoji in a notification *body string* is fine — that is data, not markup.)
- **Follow existing patterns:** `src/db/*.ts` are thin query modules; `src/lib/*` imports nothing else in the project and stays pure; boundary validation is Zod in the route.

- [ ] **Step 4: Implement `src/push/vapid.ts` and `src/push/send.ts` to the interface above**

`sendPush` must:
1. derive `audience` from `new URL(sub.endpoint).origin`
2. build the VAPID `Authorization` header via `vapidAuthHeader`
3. encrypt `payload` (aes128gcm) using `sub.p256dh` / `sub.auth`
4. `POST` to `sub.endpoint` with headers `Authorization`, `Content-Encoding: aes128gcm`, `TTL: 2419200`, `Content-Type: application/octet-stream`, and the encrypted body
5. map the response: `2xx → 'ok'`, `404 | 410 → 'prune'`, anything else → log status+body and return `'error'`
6. never throw — a network rejection is caught and returned as `'error'`

```ts
import { newId } from '../lib/ids';

export type PushSubRow = {
  id: string; user_id: string; endpoint: string;
  p256dh: string; auth: string; created_at: number;
};

/** One row per browser install. `endpoint` is UNIQUE — a re-subscribe from
 *  the same browser (possibly by a different family member on a shared
 *  device) rebinds user_id and refreshes the keys. */
export async function upsertSub(
  db: D1Database, userId: string,
  sub: { endpoint: string; p256dh: string; auth: string }, now: number,
): Promise<void> {
  await db.prepare(
    `INSERT INTO push_subs (id,user_id,endpoint,p256dh,auth,created_at)
     VALUES (?,?,?,?,?,?)
     ON CONFLICT(endpoint) DO UPDATE SET
       user_id = excluded.user_id, p256dh = excluded.p256dh, auth = excluded.auth`,
  ).bind(newId(), userId, sub.endpoint, sub.p256dh, sub.auth, now).run();
}

/** Ownership boundary: a user can only remove their own subscription. */
export async function deleteSub(db: D1Database, userId: string, endpoint: string): Promise<void> {
  await db.prepare('DELETE FROM push_subs WHERE endpoint = ? AND user_id = ?')
    .bind(endpoint, userId).run();
}

/** Prune path: the push service returned 404/410, so this endpoint is dead
 *  no matter who owns it. */
export async function deleteSubByEndpoint(db: D1Database, endpoint: string): Promise<void> {
  await db.prepare('DELETE FROM push_subs WHERE endpoint = ?').bind(endpoint).run();
}

export async function listSubsForUser(db: D1Database, userId: string): Promise<PushSubRow[]> {
  const { results } = await db.prepare('SELECT * FROM push_subs WHERE user_id = ?')
    .bind(userId).all<PushSubRow>();
  return results;
}

export async function listSubsExcept(db: D1Database, userId: string): Promise<PushSubRow[]> {
  const { results } = await db.prepare('SELECT * FROM push_subs WHERE user_id != ?')
    .bind(userId).all<PushSubRow>();
  return results;
}

/** user_ids that have BOTH an active run and at least one subscription. */
export async function usersToNudge(db: D1Database): Promise<string[]> {
  const { results } = await db.prepare(
    `SELECT DISTINCT r.user_id
       FROM runs r
       JOIN push_subs p ON p.user_id = r.user_id
      WHERE r.status = 'active'`,
  ).all<{ user_id: string }>();
  return results.map((r) => r.user_id);
}
```

```ts
import { Hono } from 'hono';
import { z } from 'zod';
import { upsertSub, deleteSub } from '../db/push';
import type { App } from './middleware';

export const push = new Hono<App>();

const subscribeSchema = z.object({
  endpoint: z.string().url(),
  keys: z.object({ p256dh: z.string().min(1), auth: z.string().min(1) }),
});
const unsubscribeSchema = z.object({ endpoint: z.string().url() });

function vapidConfigured(env: App['Bindings']): boolean {
  return Boolean(env.VAPID_PUBLIC_KEY && env.VAPID_PRIVATE_KEY && env.VAPID_SUBJECT);
}

push.get('/vapid-public-key', (c) => {
  if (!vapidConfigured(c.env)) return c.json({ error: 'push not configured' }, 503);
  return c.json({ key: c.env.VAPID_PUBLIC_KEY! });
});
```

```ts
import { api } from '../api';

export type PushState =
  | 'unsupported' | 'default' | 'denied' | 'subscribed' | 'granted-unsubscribed';

export function pushSupported(): boolean {
  return 'serviceWorker' in navigator && 'PushManager' in window && 'Notification' in window;
}

function urlB64ToUint8Array(base64: string): Uint8Array {
  const padding = '='.repeat((4 - (base64.length % 4)) % 4);
  const b64 = (base64 + padding).replace(/-/g, '+').replace(/_/g, '/');
  const raw = atob(b64);
  const arr = new Uint8Array(raw.length);
  for (let i = 0; i < raw.length; i++) arr[i] = raw.charCodeAt(i);
  return arr;
}

export async function pushState(): Promise<PushState> {
  if (!pushSupported()) return 'unsupported';
  if (Notification.permission === 'denied') return 'denied';
  if (Notification.permission === 'default') return 'default';
  const reg = await navigator.serviceWorker.ready;
  const sub = await reg.pushManager.getSubscription();
  return sub ? 'subscribed' : 'granted-unsubscribed';
}

export async function enablePush(): Promise<void> {
  if (!pushSupported()) throw new Error('This browser does not support notifications.');
  const permission = await Notification.requestPermission();
  if (permission !== 'granted') throw new Error('Notifications were not allowed.');
  const reg = await navigator.serviceWorker.ready;
  const { key } = await api.vapidKey();
  const sub = await reg.pushManager.subscribe({
    userVisibleOnly: true,
    applicationServerKey: urlB64ToUint8Array(key),
  });
  await api.pushSubscribe(sub.toJSON() as PushSubscriptionJSON);
}

export async function disablePush(): Promise<void> {
  const reg = await navigator.serviceWorker.ready;
  const sub = await reg.pushManager.getSubscription();
  if (!sub) return;
  await api.pushUnsubscribe(sub.endpoint);
  await sub.unsubscribe();
}
```

```ts
import type { Env } from '../worker';
import { todayIST } from '../lib/dates';
import { gradeDay, type GoalSnapshot } from '../lib/rules';
import { getActiveRun } from '../db/runs';
import { getProgress } from '../db/days';
import { ensureDay } from './grading';
import { usersToNudge, listSubsForUser, deleteSubByEndpoint } from '../db/push';
import { nudgeText } from '../push/messages';
import { sendPush, type VapidConfig, type WebPushSub } from '../push/send';

export type NudgeDeps = {
  send: (v: VapidConfig, s: WebPushSub, payload: string) => Promise<'ok' | 'prune' | 'error'>;
};

function vapid(env: Env): VapidConfig | null {
  if (!env.VAPID_PUBLIC_KEY || !env.VAPID_PRIVATE_KEY || !env.VAPID_SUBJECT) return null;
  return {
    publicKey: env.VAPID_PUBLIC_KEY, privateKey: env.VAPID_PRIVATE_KEY, subject: env.VAPID_SUBJECT,
  };
}

/** 21:00 IST pass. For every user with an active run and a subscription,
 *  count today's incomplete goals; if any, push a nudge to each of their
 *  subscriptions. A dead subscription (send → 'prune') is deleted. */
export async function runNudge(
  db: D1Database, env: Env, now: Date, deps: NudgeDeps = { send: sendPush },
): Promise<{ sent: number }> {
  const cfg = vapid(env);
  if (!cfg) {
    console.warn('runNudge: VAPID not configured, skipping');
    return { sent: 0 };
  }

  const today = todayIST(now);
  let sent = 0;

  for (const userId of await usersToNudge(db)) {
    try {
      const run = await getActiveRun(db, userId);
      if (!run) continue;
      const day = await ensureDay(db, run, today, userId, now);
      const snapshot = JSON.parse(day.goals_snapshot) as GoalSnapshot[];
      const progress = await getProgress(db, day.id);
      const goalsLeft = gradeDay(snapshot, progress).missedGoalIds.length;
      if (goalsLeft === 0) continue;

      const payload = JSON.stringify({
        title: '75 Hard', body: nudgeText(day.day_number, goalsLeft), tag: 'nudge',
      });
      for (const s of await listSubsForUser(db, userId)) {
        const r = await deps.send(cfg, { endpoint: s.endpoint, p256dh: s.p256dh, auth: s.auth }, payload);
        if (r === 'prune') await deleteSubByEndpoint(db, s.endpoint);
        else if (r === 'ok') sent++;
      }
    } catch (err) {
      console.error('runNudge: user failed', userId, err);
    }
  }
  return { sent };
}
```

```ts
import type { Env } from '../worker';
import { getUser } from '../db/users';
import { listSubsExcept, deleteSubByEndpoint } from '../db/push';
import { milestoneText } from '../push/messages';
import { sendPush, type VapidConfig, type WebPushSub } from '../push/send';

export type MilestoneDeps = {
  send: (v: VapidConfig, s: WebPushSub, payload: string) => Promise<'ok' | 'prune' | 'error'>;
};

function vapid(env: Env): VapidConfig | null {
  if (!env.VAPID_PUBLIC_KEY || !env.VAPID_PRIVATE_KEY || !env.VAPID_SUBJECT) return null;
  return {
    publicKey: env.VAPID_PUBLIC_KEY, privateKey: env.VAPID_PRIVATE_KEY, subject: env.VAPID_SUBJECT,
  };
}

/** One family member passed a milestone day. Notify every OTHER user who has
 *  a subscription, regardless of their own run state. Never the achiever. */
export async function sendMilestone(
  db: D1Database, env: Env, achieverUserId: string, dayNumber: number,
  deps: MilestoneDeps = { send: sendPush },
): Promise<void> {
  const cfg = vapid(env);
  if (!cfg) { console.warn('sendMilestone: VAPID not configured, skipping'); return; }

  const achiever = await getUser(db, achieverUserId);
  if (!achiever) return;

  const payload = JSON.stringify({
    title: '75 Hard', body: milestoneText(achiever.name, dayNumber), tag: 'milestone',
  });
  for (const s of await listSubsExcept(db, achieverUserId)) {
    const r = await deps.send(cfg, { endpoint: s.endpoint, p256dh: s.p256dh, auth: s.auth }, payload);
    if (r === 'prune') await deleteSubByEndpoint(db, s.endpoint);
  }
}
```

```ts
import { catchUpGrading } from './grading';
import { sendMilestone } from './milestone';
import type { Env } from '../worker';

export async function runDailyLock(
  db: D1Database, now: Date, env?: Env,
): Promise<{ graded: number }> {
  const { results } = await db.prepare(
    "SELECT DISTINCT user_id FROM runs WHERE status = 'active'",
  ).all<{ user_id: string }>();

  let graded = 0;
  for (const { user_id } of results) {
    try {
      await catchUpGrading(
        db, user_id, now,
        env ? (dayNumber) => sendMilestone(db, env, user_id, dayNumber) : undefined,
      );
      graded++;
    } catch (err) {
      console.error('grading failed', user_id, err);
    }
  }
  return { graded };
}
```
